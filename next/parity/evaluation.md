## Scoring formulas (score_forecasts)

- [x] **Input filtering**: keep `target==t` and `output_type=="quantile"`. Drop rows with null value, level, date, location or horizon. Null horizon becomes 0. Levels are rounded to 3dp. For non-negative targets (config, or a keyword heuristic on hosp/inc/count/prop/visit/death/case/admiss), negative values are clipped to 0. Then filter by locations, reference dates and the common-task join. (metrics:197-262)
- [x] **Truth join**: per target, the newest `as_of` vintage per (target_end_date, location), plus horizon when the oracle varies by horizon. Inner join, so tasks without observed truth are not scored. Duplicate quantile rows for a task are reduced to the first. (metrics:95-140, metrics:271-282)
- [x] **WIS**: per task, mean over the available quantiles of `2·(1{y<q} − τ)·(q − y)`. For a symmetric 2K+1 set this equals `1/(K+½)·[½|y−m| + Σ αₖ/2·ISₐₖ]`. (metrics:290-307)
- [x] **Log scale**: the same pinball loss on `ln(max(y,0)+1)` against `ln(max(q,0)+1)` gives `wis_log`. `mae_log = |ln(y⁺+1) − ln(m⁺+1)|`. Relative WIS, Δ% and wins all have log variants computed from `wis_log`. (metrics:284-301, metrics:343-351)
- [x] **WIS-7**: the mean on the 7 standard levels (0.025, 0.1, 0.25, 0.5, 0.75, 0.9, 0.975) when all are present. Returned but not shown. (metrics:32, metrics:309-318)
- [x] **MAE**: `|y − q0.5|` per task, then the mean. Null if there is no median. (metrics:342-354)
- [x] **Coverage**: cov95 = share of y in [q0.025, q0.975], inclusive. cov50 = share of y in [q0.25, q0.75]. Both ×100. Calibration: for every symmetric pair (q, 1−q), nominal 1−2q, rounded to 1dp %. (metrics:356-415, metrics:517-522)
- [x] **Sharpness column**: the mean of (q0.975 − q0.025), clipped ≥0. This is the 95% PI width, not the WIS spread component. (metrics:366)
- [x] **Decomposition**: norm = 1/(K+½) over K symmetric pairs. Spread = Σ (α/2)(u−l). Over = ½·max(0, m−y) + Σ max(0, l−y). Under = ½·max(0, y−m) + Σ max(0, y−u). Null when there are no pairs or no median. (metrics:397-427)
- [x] **Per-100k**: per task `wis/population·100000` (null without a population), then the mean. The population map is null for `is_rate` targets (e.g. `wk inc flu prop ed visits`), so the column is null for them. (metrics:434-448, eval:820-824)
- [x] **Location pooling**: if any non-US location is scored, the overall (leaderboard) metrics, by_horizon and count use states only. Otherwise they use US only. `states_wis` and `us_wis` are reported separately. With location=all, US is therefore excluded from WIS, rel WIS, Δ%, coverage, MAE and wins. (metrics:450-553, eval:543-551)
- [x] **count**: the number of scored tasks (reference_date × location × horizon × target_end_date) in the primary pool. `evaluated_dates_count` and `locations_count` are taken over all scored rows, US included. (metrics:494, metrics:555-576)
- [x] **Quantile flags**: `quantile_count` is the number of distinct levels. `has_23_quantiles` means the 23 standard levels are a subset. A validation warning is added when the count is <7: "Model '{id}' has only {n} quantiles (standard is 7 or 23).". (metrics:264-268, eval:782-786)

## Relative WIS, Δ% and wins

- [x] **Pairwise tournament relative WIS**: computed over every scored model, the background baseline included, in the primary pool. For each pair, take the ratio of mean WIS on their shared tasks, and only when both means are >0. θᵢ is the geometric mean of the ratios, including its self-ratio of 1. A model needs at least one other comparator, otherwise θ is null. rel = θᵢ/θ_baseline, rounded to 4dp, and null if the baseline θ is null. The same is done on `wis_log`. (metrics:625-739, eval:577-583)
- [x] **Effective baseline fallback**: if the configured baseline has no scored tasks, the first scored model whose name contains "baseline" is used, else "ensemble", else the first scored model. A warning is added: "Baseline '{b}' has no forecasts in this scope; relative WIS and Δ% are scaled to '{e}' instead." (or "No baseline model found; ..."). The response's `baseline_model` is the effective one. (eval:553-571, eval:799)
- [x] **Δ% vs baseline, fair mode**: `(wis − wis_base)/wis_base·100` on the common task set (log likewise). The baseline is scored on common tasks computed among the requested models only, so an unselected baseline may cover only part of that set. **(quirk)** (eval:692-699)
- [x] **Δ% vs baseline, unconstrained**: computed on the tasks shared by the model and the baseline (same pool rule), as the difference of means. The baseline itself gets 0.0. Null when nothing is shared or base WIS ≤0. Rounded to 1dp. (eval:686-726, eval:73-89)
- [x] **Wins**: computed over requested models only (not the background baseline), and only when at least 2 have scores. Per round, n = models with any task that round. Shared tasks are those all n forecast, with n≥2. The lowest mean WIS on the shared tasks wins, and ties within 1e-9 relative all win. `competed` counts rounds where the model took part in shared tasks. Same on `wis_log` → `weeks_won_log`. With a single model, wins are null and the cell shows `--`. (eval:274-313, eval:573-575)
