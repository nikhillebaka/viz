# Shell, state and modals

Parity inventory for the old Plotly frontend (`static/`): app shell, global state, URL handling, top-level controls and modals. View internals (fan chart, spatial map, heatmap, peak view) and component internals (leaderboard table, diagnostics, eval-window popover, ensemble studio, live hubs) are covered elsewhere; here only how the shell hosts and switches them.

File abbreviations: `html` = static/index.html, `main` = static/js/main.js, `state` = static/js/state.js, `const` = static/js/constants.js, `api` = static/js/api.js, `ctl` = static/js/components/controls.js, `mod` = static/js/components/modals.js.
